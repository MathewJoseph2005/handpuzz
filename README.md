# Project: Last Horizon

A hand-controlled live puzzle terminal built with React, TypeScript, and Vite.

## Current checkpoint

The project currently contains the first visual checkpoint: a restrained doomsday command-terminal BOOT screen with staged diagnostics, local-processing privacy copy, responsive layout, scanlines, grain, vignette, graphite surfaces, storm-cyan accents, olive shadows, and amber system states.

## Commands

```text
npm install
npm run dev
npm run typecheck
npm run build
```

Camera and hand tracking will be added in the next implementation checkpoints. The finished app is intended to run locally with camera frames and leaderboard data kept on-device.
